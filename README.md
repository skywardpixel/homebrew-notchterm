# Homebrew Tap for NotchTerm

A drop-down terminal for macOS that emerges from the notch area.

## Installation

```bash
brew tap skywardpixel/notchterm
brew install --cask notchterm
```

Or directly:

```bash
brew install --cask skywardpixel/notchterm/notchterm
```
